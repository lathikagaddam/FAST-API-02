# 📍 PIN Code Lookup API using FastAPI

## 📌 Project Overview

The PIN Code Lookup API is a beginner-friendly project developed using **FastAPI**. It allows users to enter an Indian PIN code and retrieve location details associated with that PIN code.

The project demonstrates how FastAPI can be used to build REST APIs and handle user input to fetch useful information.

## 🚀 Features

- Search location details using an Indian PIN code.
- Retrieve details associated with the entered PIN code.
- REST API development using FastAPI.
- Input validation and error handling.
- Interactive API documentation using Swagger UI.

## 🛠️ Technologies Used

- Python
- FastAPI
- Uvicorn
- REST API
- JSON

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd Lookup-Code
```

**3. Install dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the FastAPI application**

```bash
uvicorn main:app --reload
```

## 🌐 API Documentation

After starting the application, open:

- Swagger UI: `http://127.0.0.1:8000/docs`
- ReDoc: `http://127.0.0.1:8000/redoc`

## 💡 How It Works

1. Enter an Indian PIN code through the API.
2. The application processes the PIN code.
3. It retrieves the corresponding location information.
4. The API returns the details in JSON format.
